**User stories — Smart Campus study room booking**

**US-01**  
**Story:** As a Student, I want to view available study rooms, so that I can choose a suitable room for studying.  
   
 **Priority:** High  
   
 **Assumption:** Room availability information is updated in the system.  
**US-02**  
**Story:** As a Student, I want to book an available study room for a specific time, so that I can use the room when I need it.  
   
 **Priority:**High  
 **Assumption:** Students can only book rooms that are available for the selected time.  
**US-03**  
**Story:** As a Student, I want to view my bookings, so that I can check my upcoming study room reservations.  
   
 **Priority:**Medium  
 **Assumption:** Each student can see only their own bookings.  
**US-04**  
**Story:**As a Student, I want to cancel my booking, so that the room becomes available when I no longer need it.  
   
 **Priority:**Medium  
 **Assumption:** Students can cancel their own future bookings.  
**US-05**  
**Story:** As an Administrator, I want to block or unblock a study room, so that rooms under maintenance cannot be booked by students.  
   
 **Priority:**High  
 **Assumption:** Administrators have permission to manage room status.  
**US-06**  
**Story:** As an Administrator, I want to review room usage, so that I can monitor how study rooms are being utilized over a period.  
   
 **Priority:**Medium  
 **Assumption:** Administrators can access all historical and upcoming bookings in the system.  
**US-07**  
**Story:** As a Student, I want to receive a confirmation when I book or cancel a room, so that I know my action was successful.  
   
 **Priority:**High  
**Assumption:** The system can send automated messages to students.
